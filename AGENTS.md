# Contexto do repositório

Finalidade: API didática para gestão de alunos, matrículas e avaliações físicas, construída com Spring Boot e Spring Data JPA.

Tecnologia: Java, Maven Wrapper, Spring Boot, JPA e PostgreSQL.

Restrições: Configurar PostgreSQL conforme o projeto e conferir as propriedades reais; não executar em produção com credenciais de exemplo.

Preservar estrutura existente e nomes dos módulos. Ler docs/REQUISITOS.md, docs/ARQUITETURA.md e README.md antes de alterar. Priorizar documentação clara em português, testes compatíveis com a stack, validação de integrações e segurança de segredos. Não alegar builds aprovados sem execução.
